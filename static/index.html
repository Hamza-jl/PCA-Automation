Étape 1 — Charger l'organigramme
OCR structurel — Lit toutes les boîtes par position géométrique. Rapide (~3s), aucune hallucination, aucun modèle IA requis. Idéal pour les organigrammes avec étiquettes de niveaux (Directions centrales, Agences…).  ⚠ EasyOCR non installé — pip install easyocr
Mode hybride — OCR extrait les noms + positions (zéro hallucination), puis le LLM organise la hiérarchie via les coordonnées Y. Fonctionne avec n'importe quel modèle Ollama (pas besoin de modèle vision).
GLM-OCR — Modèle OCR spécialisé (0.9B, #1 OmniDocBench) via Ollama. Lit le texte avec une précision maximale, sépare automatiquement rôle et titulaire, groupe par niveau structurel. Rapide sur votre GPU (~10s).  ⚠ GLM-OCR non disponible — ollama pull glm-ocr
Modèle vision (VLM) — Le modèle analyse l'image seul. Utile pour les organigrammes sans structure géométrique claire (schémas libres, images floues).

Aucun modèle vision détecté. Installez-en un : ollama pull granite3.2-vision:2b
