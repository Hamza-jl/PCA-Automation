Étape 1 — Charger l'organigramme
Analyse simple (OCR) — Lit toutes les boîtes par position géométrique. Rapide (~3s), aucune hallucination, aucun modèle IA requis. Idéal pour les organigrammes avec étiquettes de niveaux (Directions centrales, Agences…).  ⚠ EasyOCR non installé — pip install easyocr
Analyse avancée — Découpe l'image en bandes horizontales pour une lecture plus précise par un modèle vision, puis relie la hiérarchie bande par bande. Plus lent (plusieurs minutes) mais bien plus fiable sur les organigrammes denses.
